### What I work on

- **Platform and infrastructure**: multi-account AWS and multi-project GCP, all as Terraform, with Kubernetes (GKE, EKS, k0s) and GitOps (Argo CD, Argo Rollouts)
- **Reliability and observability**: Datadog, Prometheus and CloudWatch, incident response, anomaly detection and cost reporting
- **Security**: container and dependency scanning (Trivy, Grype, Syft), DefectDojo, Checkov, cross-cloud workload identity (AWS and GCP federation)
- **FinOps**: cost visibility, Savings Plans and rightsizing
